## Project: GitHelper

GitHelper is a lightweight, high-performance Git GUI application built with Tauri v2 and Svelte 5. The project has just been updated to comply with the Antigravity Document Registry standards, centralizing memory and tracking system state in memory.md and summary.md.


The project documentation has been fully migrated to the Document Registry standard, tracking data models, architecture, IPC APIs, features, and project rules in separated structured files.
